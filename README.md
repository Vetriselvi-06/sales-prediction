# Sales Prediction Using SVR

This project predicts sales revenue using Support Vector Regression (SVR).

## Technologies Used

* Python
* Pandas
* Scikit-learn
* Joblib

## Input Features

* Quantity
* UnitPrice

## Target

* TotalRevenue

## Machine Learning Process

1. Load the dataset
2. Select input and target
3. Split the data
4. Scale the features
5. Train the SVR model
6. Predict revenue
7. Evaluate the model using MAE and R2 Score
8. Save the trained model as `model.pkl`
